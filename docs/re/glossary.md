# Glossary

| Term | Definition | Source |
|---|---|---|
| Tenant | A barbershop business (trade name) subscribed to the platform; owns one or more branches. Created only by the Platform Operator. | SH-01 |
| Branch | A physical shop belonging to a tenant, located in one city. | SH-01 |
| Employee | A person employed by a tenant, assigned to exactly one branch at a time; either a barber or a non-barber. | SH-01 |
| Barber | An employee who performs services for customers. | SH-01 |
| Branch Manager | An employee (barber or non-barber) assigned to manage exactly one branch; a branch has at most one. A branch without a manager is managed directly by the Tenant Admin, who then holds all branch-manager permissions. | SH-01 |
| Tenant Admin | The user account managing a tenant. | SH-01 |
| Platform Operator | The commercial owner and administrator of the platform. | SH-01 |
| Customer | A person using the customer app to find barbers and book services. | SH-01 |
| Transfer | Moving an employee to another branch of the same tenant, by the Tenant Admin only. **Temporary** (with an end date; automatic return) or **permanent**. | SH-01 |
| Plan | A subscription offering (free or paid). Each plan has a numeric **plan level** used for search ordering. | SH-01 |
| Plan-Feature Matrix | Operator-managed configuration defining which features (and feature values, e.g. included preview credits, contact type) each plan provides, changeable without an app release. | SH-01 |
| Service | An item in the tenant-wide service catalog with a duration and a commission rate defined by the tenant; price and activation are set per branch. | SH-01 |
| Booking | An appointment for one or more services, on a specific barber or on a branch (barber assigned later). | SH-01 |
| Completed Booking | A booking marked completed by the assigned barber or the branch manager (or the Tenant Admin when the branch has no manager), with the paid amount and currency recorded per service. | SH-01 |
| AI Haircut Preview | An image generated by an AI provider showing the customer with a chosen haircut, from a photo uploaded by the customer; available only within a booking and only to granted customers. | SH-01 |
| Preview Retention | Rule for deleting the customer photo and preview from the server: immediately on booking cancellation; on booking completion; otherwise after a configurable period from the appointment time (default 24 hours), whichever comes first. A copy remains on the customer's device. | SH-01 |
| Preview Credit | A unit allowing one AI haircut preview. Held by the tenant in credit batches. | SH-01 |
| Credit Batch | A set of preview credits with one expiry date: one calendar month from purchase or plan renewal (last day of the month when the day does not exist). | SH-01 |
| Preview Quota | Number of previews granted by a tenant to a named customer; reserved from the tenant's credits at grant time. | SH-01 |
| Discount Code | A promotion code defined by the tenant (percentage or fixed amount, expiry, usage limits, eligible services/branches), entered by the customer at booking. | SH-01 |
| Code Audience | Who may use a discount code: all customers, the favorite customers of a given barber, or named customers. | SH-01 |
| Favorite Barber | A barber marked as favorite by a customer. | SH-01 |
| Favorite Customer | A customer added by a barber to the barber's favorites by scanning the customer's QR code; the customer is notified and may refuse or remove it. | SH-01 |
| Supply Catalog | Tenant-defined list of supply items (name, unit of measure). | SH-01 |
| Supply Request | A branch manager's request to the tenant for supply items (catalog or free items with quantity). Statuses: Submitted → Approved / Rejected (with reason) → Purchased/Delivered. | SH-01 |
| Payroll Statement | Monthly statement per barber: salary + per-service commission on paid amounts + manual advances, deductions and bonuses; calculated in SYP. | SH-01 |
| Exchange Rate Snapshot | The SYP/USD rate stored with each financial record at the moment it is created. | SH-01 |
| SYP | The new Syrian pound (after redenomination); the platform's default currency. | SH-01 |
| Unavailability Period | A period within branch working hours when a barber cannot be booked (leave, break), recorded by the Branch Manager. | SH-01 |
| Barber Priority Order | Tenant-defined ordering of a branch's barbers used to auto-assign branch-level bookings to the highest-priority available barber. | SH-01 |
| No-show Ban | A tenant-level, permanent (until lifted by the tenant) block on new bookings by a customer after a tenant-defined number of no-shows. | SH-01 |
| Plan Level | Numeric rank of a plan set by the operator; higher levels rank higher in search results; the free plan ranks last. | SH-01 |
| Grace Period | Operator-configured period after paid-subscription expiry during which the tenant keeps its paid plan before falling back to the free plan. | SH-01 |
| Credit Pack | Operator-defined bundle of preview credits with a price, purchasable by tenants. | SH-01 |
| Booking Status | Pending (manual confirmation) → Confirmed → Completed, or Rejected, Cancelled, No-show. | SH-01 |
| Active Booking | A booking in status Pending or Confirmed. | SH-01 |
| Tenant Feature | A capability enabled or disabled per plan in the plan-feature matrix: prices display, booking, maps navigation, discount codes, AI haircut preview. The contact action is available on every plan; only its type (phone call or in-app chat) is set per plan. | SH-01 |
